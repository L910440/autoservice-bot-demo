# Демо-бот записи на ремонт в автосервисе

Прототип для отклика на заказ FL.ru №5521312 «ИИ Агент для записи в автосервис».

## Что реализовано и проверено

- Запись по шагам через кнопки: пост (1-4) → дата → время → услуга → имя/телефон клиента
- Проверка занятости слота (пост+дата+время), нельзя записать двух клиентов на одно время
- `/расписание` — список записей на сегодня по постам
- `/мои` — список своих записей с отменой в один клик
- Запись голосом: распознавание речи (Deepgram STT) + разбор даты/времени/поста/услуги/клиента из текста — если бот понял все поля, создаёт запись сразу; если не хватает данных — просит уточнить
- Хранение — простой JSON-файл (`data/bookings.json`), без внешней базы
- Логика хранения и разбора голоса покрыта тестами: `npm test`

## Что специально НЕ сделано (честно, по ТЗ и по здравому смыслу)

- Интеграция с 1С Альфа-Авто — заказчик сам просит обойтись без неё
- Синхронизация с Google Calendar — заглушка с понятным сообщением клиенту.
  Настоящая интеграция требует доступ к Google-аккаунту самого автосервиса
  (OAuth или сервисный ключ) — это подключается на этапе реальной работы,
  когда есть доступ к их календарю. Код готов к этому: как только появится
  `GOOGLE_CALENDAR_CREDENTIALS`, функция `calendarNote()` в `bot.js` — точка,
  где добавляется реальный вызов Calendar API
- Индивидуальный доступ по мастерам (сейчас у всех доступ ко всем постам) —
  для демо не критично, в реальном проекте — это список Telegram user id
  по постам, добавляется быстро

## Как запустить

1. Получить токен Telegram-бота (см. следующий раздел)
2. `AUTOSERVICE_BOT_TOKEN=<токен> DEEPGRAM_API_KEY=<опционально> node bot.js`

## Как получить токен для живого демо

Самый простой способ — через встроенную функцию платформы: в Telegram-боте
Эммануэлы `/settings → 🤖 Мои боты` (заводит дополнительного бота
автоматически). Второй способ — вручную через `@BotFather` в Telegram:
`/newbot` → следовать подсказкам → полученный токен добавить в
`/settings → 🔑 Переменные окружения` под именем `AUTOSERVICE_BOT_TOKEN`.
